このサイトについて・読み方

議会の配信動画は、多くが YouTube で、映像や音声のファイルは手に入りません。記録を自前で持つには、現地で録るしかありません。記者が行けないときは、地元の住民に頼む手もあります。そのときに、録れるか・何をすればよいかを調べるためのサイトです。

例規集（条例・規則）を探したが、見つからなかった
  • 「住民」は、記者に頼まれて、報道に使う目的で録る場合です。報道目的の撮影だけを許可制にしている議会では、住民でも申請が要ります。
  • 傍聴規則などの条文（例規集）と、議会サイトの傍聴案内の両方を見て判断しています。案内が規則より厳しい議会は、案内に合わせています。
  • 本会議は、どの議会でも誰でも傍聴できます（地方自治法115条。秘密会を除く）。委員会は、委員長の許可が要る議会もあります。
  • 許可が実際に下りるか、何に使ってよいかは、規則からは分かりません。必ず議会事務局に確かめてください。
  • 「映像を手に入れる」は、議会が映像を出す・貸す・使ってよいと書いているかです。比べると、米国ユタ州では会議の録音は公文書で、会議後3営業日以内に誰でも聞けるようにすることが法律で決まっています（Utah Code 52-4-203）。
  • 条文は調査日の時点のものです。その後に改正されていることがあります。
  • 「条文を開く」は根拠の条へ直接飛びます（Chrome、Edge、Safari）。Reiki-Base 方式の例規集は固定のリンクがないため、検索語をコピーして探してください。
  • 条例・規則は著作権の対象外です（著作権法13条）。
配信の映像をダウンロード・録画してよいか
  • 見ながらメモを取り、記事にするのは問題ありません。
  • YouTube の映像をツールでダウンロードするのは、規約違反です。YouTube と権利者の事前の書面許可が要ります（利用規約）。
  • 議会の配信サイトは、多くが「著作権法で認められた範囲を超えて複製しない」としています。仕事での保存は「私的使用」（著作権法30条）に当たりません。
  • 新聞・放送は、議会での公開の発言を、報道の目的上正当な範囲で載せたり流したりできます（40条2項）。時事の報道に伴う複製（41条）・引用（32条）もあります。ネットだけの媒体が自社サイトに載せることは、40条2項に書かれていません。
  • 映像が要るときは、議会事務局に提供を申請するのが確実です。「知りたいこと」の「映像を手に入れる」で、映像を貸し出す・提供する議会が分かります。
  • 画面や音声を録って文字起こしすることを、規約や法がどう扱うかははっきりしません。
