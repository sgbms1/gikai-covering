# 地方議会の傍聴・録音・中継の一覧

全国の地方議会（都道府県・市区町村の1,788議会）について、**傍聴席で録音・撮影できるか**と、**生中継・録画配信があるか**を、規則の原文つきで一覧にしたサイトです。

読者として主に記者（新聞・放送・フリー）を想定しています。生中継があれば、それを見ながら取材できます。なければ現地で録るしかありません。記者が行くか、住民に頼むか、委員会まで録れるか。その作戦を立てるために作りました。

- `index.html` — 都道府県を選ぶと、その県の全議会が一覧になります。中心は「本会議／委員会 × 記者／住民」の4マス（自由／申請／要確認／不可／不明）です。
- `compare.html` — 都道府県ごとの割合を地図で比べます。

## 見方の注意

- **「確認できず」は「ない」という意味ではありません。** 規則や配信のページを見つけられなかったものです。サイトの停止で開けなかったものも含みます。
- 2026年10月の時点の調べです。規則や配信はあとで変わることがあります。取材の前に、議会事務局に確かめてください。
- 規則に書いてあることと実際の運用が違う議会もあります。報道向けの手続きは、規則とは別の案内ページに書かれていることが多いので、それもあわせて読んでください。
- 法的な助言ではありません。配信のダウンロードと著作権法の整理は [docs/download_law.md](docs/download_law.md) にあります。

## 調べ方

各議会の例規集（傍聴規則・会議規則・委員会条例）、傍聴の案内ページ、配信のページを取得しました。分類には機械の判定と AI（Claude）を使い、判断が分かれるものは人が原文で確かめています。根拠には、元のページの文と URL を載せています。

## データ

- `data/<都道府県コード2桁>.js` — その県の全議会のデータ（1議会1件）
- `data/pref_stats.js` — 都道府県ごとの集計
- `data/geo/` — 地図の境界

## 誤りの指摘

誤りや新しい情報は [Issue](../../issues/new/choose) で知らせてください。原文で確かめてから直します。確かめられないものは「確認できず」のままにすることがあります。
