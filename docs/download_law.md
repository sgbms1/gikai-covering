# 議会中継のダウンロード・録画と報道での利用（2026-10-18 調べ）

議会の配信映像を、記者がダウンロード・録画して報道に使ってよいかの整理。下の引用は、原文の取得・照合が済んだものだけ。未確認のものは「未確認」とした。法的な助言ではない。個別の判断は弁護士・議会事務局に確かめる。

## 1. YouTube の利用規約（2023年6月1日発効）
- ダウンロードは原則禁止。例外は「本サービスによって明示的に承認されている場合」か「YouTube および各権利所持者が事前に書面で許可している場合」だけ。議会（投稿者）が許可するだけでは足りず、YouTube の書面許可も要ると読める。
  - 出典: https://www.youtube.com/static?template=terms&hl=ja&gl=JP 「本サービスまたはコンテンツのいずれかの部分に対しても、アクセス、複製、ダウンロード、配信、送信、放送、展示、販売、ライセンス供与、改変、修正、またはその他の方法での使用を行うこと。ただし、（a）本サービスによって明示的に承認されている場合、または（b）YouTube および（適用される場合）各権利所持者が事前に書面で許可している場合を除きます。」
- YouTube Premium の「オフライン」は、アプリの中での一時保存。ファイルを取り出す機能ではない（https://support.google.com/youtube/answer/6308116?hl=ja）。
- 画面や音声を別の機器で録る行為について、規約に明示の記述はない（未確認）。

## 2. 議会・自治体の決まり（3都府県の調べから）
- 多くの議会は「著作権法で許された範囲を超えて複製しないでください」「『私的使用のための複製』や『引用』など著作権法上認められた場合を除き、無断で複製・転用することはできません」と書く。サイトでは「法の範囲内だけ」と表示する。
- 例外の付かない禁止もある。例: 西東京市 https://www.city.nishitokyo.lg.jp/sigikai/gikai-internet/honkaigi20210318.html 「映像および音声は、オンラインでの視聴以外の利用（ダウンロード、複製、転用等）が禁止されています。」
- 許可制の例: 真鶴町 https://www.town.manazuru.kanagawa.jp/soshiki/gikai/plenary/1416.html 「会議映像（静止画を含む。）を許可なく二次利用、加工、転用することは禁止です。使用を希望する場合は、議会事務局までご連絡ください。」
- 報道機関への映像提供: 堺市議会は、報道機関に申請・議長決裁で中継映像の使用を許可している（議会運営の検討資料。提供形式に MP4 がある）。https://www.city.sakai.lg.jp/shigikai/kaigi/kojo/kojo83-.files/86sryou-2.pdf
- ダウンロードを明示的に認める議会や、mp4・mp3 を公開する議会、API は、3都府県とほかの調べでは見つからなかった（未確認）。

## 3. 著作権法（e-Gov 法令検索の現行条文。https://laws.e-gov.go.jp/law/345AC0000000048）
- 第30条（私的使用のための複製）: 記者の業務での複製には当たらない（文化庁の資料「仕事での利用は×」 https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/seminar/2024/pdf/94088901_01.pdf）。
- 第40条1項: 「公開して行われた政治上の演説又は陳述…は、同一の著作者のものを編集して利用する場合を除き、いずれの方法によるかを問わず、利用することができる。」ただし、議会の質疑応答や答弁には1項の適用はないという見解が有力（一般財団法人地方自治研究機構、2013年 https://www.rilg.or.jp/htdocs/main/houmu_qa/2013/32_spring02.html 「議会における質疑応答や答弁等については同条１項の適用はないという見解が有力です。」）。
- 第40条2項: 「地方公共団体の機関…において行われた公開の演説又は陳述は、…報道の目的上正当と認められる場合には、新聞紙若しくは雑誌に掲載し、又は放送し、有線放送し、地域限定特定入力型自動公衆送信を行い、若しくは放送同時配信等を行うことができる。」新聞・雑誌・放送（と放送同時配信）に限られ、ネットメディアが自社サイトだけに載せることは列挙されていない（前出の地方自治研究機構の解説も「ウェブサイトにアップロードする行為は、現状、ここに含まれておりません」）。
- 第41条: 「写真、映画、放送その他の方法によつて時事の事件を報道する場合には、当該事件を構成し、又は当該事件の過程において見られ、若しくは聞かれる著作物は、報道の目的上正当な範囲内において、複製し、及び当該事件の報道に伴つて利用することができる。」
- 第32条（引用）: 公正な慣行に合致し、報道・批評などの目的上正当な範囲内であること。
- 映像の権利: 議会事務局が作った映像は職務著作として自治体が著作者になりうる。議員の創作性のある発言は議員の著作物（前出の地方自治研究機構）。業者が撮影した場合の扱いは未確認。
- 議会の利用規約が、40条・41条で認められる利用をどこまで制限できるか: 権威ある解説は見つからなかった（未確認）。

## 4. 記者にとっての目安（サイトの「読み方」に短くして載せる）
- 配信を見ながらメモを取り、発言を記事にするのは問題ない。
- 新聞・放送が報道のために発言を載せる・流すことは、40条2項・41条の範囲でできる。
- YouTube の映像をツールでダウンロードするのは、規約違反になる（YouTube の書面許可がない限り）。
- 議会の配信サイトのダウンロードも、多くの議会は「法の範囲内だけ」としている。業務での保存は私的使用に当たらない。映像が要るときは議会事務局に提供を申請するのが確実（堺市は報道機関に提供）。
- 画面・音声を録って文字起こしすることや、議会の規約と40条・41条の関係は、はっきりしない。
